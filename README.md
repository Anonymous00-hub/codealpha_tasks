&#x20;**Projects**



&#x20;**Task 1 : Flashcard Quiz App**



A simple flashcard application designed to help users create and study their own flashcards.



&#x20; **Main features:**



* Add new flashcards
* View saved flashcards
* Edit and delete flashcards
* Study flashcards one at a time
* Show and hide answers
* Move between previous and next cards
* Simple and clean Android interface



&#x20; **Package:** com.salisou.flashcardquizapp







&#x20;   **Task 2 : Random Quote Generator**



A lightweight application that displays random motivational and inspirational quotes.



&#x20; **Main features:**



* Display a quote and its author
* Generate a new random quote
* Simple quote card interface
* Clean and responsive layout



&#x20; **Package:** com.salisou.randomquotegenerator







&#x20;   **Task 3 : Fitness Tracker**



A fitness tracking application for recording daily activities and viewing basic progress.



&#x20; **Main features:**



* Record daily steps
* Log workout activities
* Track calories burned
* Record workout duration
* Select exercise types
* View activity history
* Edit and delete saved activities
* Daily activity summary
* 10,000-step progress indicator
* Weekly activity summary
* Seven-day activity chart
* Local data storage using SQLite



&#x20; **Package:** com.salisou.fitnesstracker

&#x20;  **Running the Projects**



Each task is a separate Android Studio project.

To run a project:

1\. Open the task folder in Android Studio.

2\. Allow Gradle to sync and finish downloading any required dependencies.

3\. Connect an Android device or start an emulator.

4\. Build and run the application.
